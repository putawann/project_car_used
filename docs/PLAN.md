## 3. ที่รันและที่เก็บงาน
- **Colab เป็นแหล่งหลักของโน้ตบุ๊ก** — ลบสำเนาโน้ตบุ๊กในเครื่องแล้ว
- **ไม่บันทึกไฟล์ใด ๆ ลงเครื่อง/ดิสก์** — ไม่มีไฟล์สรุป ไม่มีไฟล์ข้อมูลแปลง ไม่มีไฟล์โมเดล ทุกอย่างแสดงผลบนหน้าจอเท่านั้น
- ผลกระทบที่ยอมรับ: ถ้า Colab runtime รีเซ็ต ต้องรันใหม่ทั้งหมด (เทรนใหม่ ยอมรับได้)

## 4. โน้ตบุ๊กปัจจุบัน (ขั้นนำเข้าข้อมูล — ยังไม่เทรน)
7 เซลล์: 1 เซลล์ข้อความอธิบาย + 6 เซลล์โค้ด

| ขั้น | ทำอะไร |
|---|---|
| 1 | เชื่อม Google Drive + อ่านไฟล์จาก path ที่กำหนด แล้วพิมพ์ขนาดข้อมูล |
| 2 | พิมพ์ขนาด/ชื่อคอลัมน์ + หัวตาราง |
| 3 | ค่าว่าง แถวซ้ำ ชนิดข้อมูล สถิติพื้นฐาน |
| 4 | นับค่าหมวดหมู่ทุกคอลัมน์ |
| 5 | กราฟราคา/อายุรถ/เลขไมล์/ความจุเครื่องยนต์ |
| 6 | เตรียม split 80/20 seed 99 (ยังไม่เทรน) |

## 5. โปรโตคอลกลาง (บังคับใช้ตั้งแต่เฟส DT)
- seed = 99
- split train 80% / test 20%
- KFold 5 เฉพาะ train (shuffle, seed 99)
- fit การแปลงข้อมูลจาก train เท่านั้น กันข้อมูลรั่ว
- test แตะครั้งเดียว หลังเลือกค่าที่ดีที่สุดจาก CV แล้ว
- ห้ามใช้ test ช่วยเลือกหรือจูนโมเดล

## 6. ลำดับโมเดล (ตามคำสั่งเจ้านาย)
1. DT (Decision Tree)
2. RF (Random Forest)
3. XGB
4. MLR

## 7. กติกา human in loop
- บ๊อบ: เขียนโค้ดเป็นเซลล์ อธิบายว่าเซลล์ทำอะไร อ่านผลจากเซลล์เองผ่าน MCP แล้ววิเคราะห์ เสนอจุดเสี่ยง
- เจ้านาย: เป็นคนกด Run ทุกเซลล์ (บ๊อบไม่กดรัน)
- บ๊อบไม่ข้ามไปโมเดลถัดไปก่อนเจ้านายอนุมัติ

## 8. เกณฑ์จบแต่ละขั้น
- **นำเข้าข้อมูล:** อ่านไฟล์ได้ · เห็นขนาดและหัวตาราง · ดูค่าว่าง/แถวซ้ำ/ค่าหมวดหมู่/กราฟครบ (ไม่มีการบันทึกไฟล์ใด ๆ)
- **DT:** ตาราง CV (5 fold) + test MAE/RMSE/R² แสดงบนหน้าจอ + ดูได้ว่าต้นไม้ตัดที่ค่าไหน
- (ตัวอื่นกำหนดเพิ่มเมื่อถึงขั้นนั้น)

## 9. ผลลัพธ์ท้ายโปรเจกต์
- ตารางเทียบ CV/Test ของ 4 โมเดล + กราฟ + สรุปว่าตัวไหนเหมาะกับโจทย์และเพราะอะไร (แสดงในโน้ตบุ๊ก/แชท)
- ตัวอย่างทำนายราคารถจริง 1-2 คัน

## 10. ข้อควรระวัง
- แท็บ Colab ต้องล็อกอินบัญชีที่เป็นเจ้าของโฟลเดอร์ `Project/cardb` ไม่งั้นเจอ FileNotFoundError ทันที (ไม่มีทางสำรองแล้ว)
- ต้องกด Ctrl+S เก็บเล่มลงไดรฟ์ เล่มยังไม่ได้ตั้งชื่อ ถ้าแท็บหลุดเซลล์หายหมด
- บ๊อบกดไดอะล็อก Connect/OAuth ของ Chrome เองไม่ได้ ถ้า bridge หลุดต้องให้เจ้านายกด
- seed 99 ทำให้เทียบตัวเลขกับ V2 (seed 42) ตรง ๆ ไม่ได้ ใช้เป็นบริบทเท่านั้น
- ลำดับ DT ก่อน MLR ต่างจากปกติ (ปกติ MLR เป็นฐานง่ายสุด) — ทำตามที่เจ้านายสั่ง
- RF/XGB อาจใช้เวลานาน ต้องจำกัดการค้นค่าและขออนุมัติก่อนรัน
