## ที่ตั้งเอง (ไม่มีแหล่งรองรับตรง ๆ)
- **เกณฑ์ระบุ placeholder ไมล์:** อายุ >= 2 ปี และไมล์ <= 2,500 กม. (`PLACEHOLDER_MIN_AGE`, `PLACEHOLDER_MILEAGE`) มาจากข้อมูล (2,538 คันอายุ >= 2 ที่ไมล์ 2,500 พอดี; 77% ของไมล์เป็นพหุคูณของ 2,500) ; มัธยฐานกม./ปี เป็นค่าแทน
- **รวมสีซ้ำ:** `Grey Bronze`->`Grey`, `Silver Bronze`->`Silver`, `Gold Bronze`->`Golden` (ตามที่ผู้ใช้ระบุว่าป้ายสีซ้อนกัน)
- **ขอบเขตการรวมระดับหายาก:** ใช้กับ `color` เท่านั้น (ค่า 19 มาจาก FES)
- **`TOL` = 2%, `ALPHA` = 0.05, `VIF_MAX` = 7, `DW_RANGE` = 1.5-2.5, `REDUNDANT_MAX` = 0.95, 80/10/10, seed 99:** ค่าเดิมของ MLR4
- **กฎการเลือกตัวแปรของ MLR4_fix:** ตัวแปรตัดได้เมื่อ CV MAE (log) แย่ลง <= TOL และ (p > ALPHA หรือ มี dummy ที่ VIF >= VIF_MAX) ; เติม slope อายุ x รุ่นเมื่อ CV ดีขึ้น > TOL
- **`FGLS_ITERS` = 2, `VAR_FLOOR` = 0.1:** ตั้งเอง (ลอง 1, 2, 3 รอบ ดู worklog)
- **ตัด outlier แค่ 1 รอบจาก OLS** ; **Breusch-Pagan ใช้ X ไม่ถ่วงน้ำหนัก** (เหตุผลในหัวข้อ 9 ของ notebook)
- **กลุ่ม Normality "ผ่าน" ด้วยเกณฑ์ n ใหญ่ (Mishra 2019) ไม่ใช่ด้วย p-value** : Lilliefors และ Shapiro-Wilk (5,000 ตัว) ไม่ผ่านจริง รายงานไว้ใน notebook
